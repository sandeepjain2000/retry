Purpose
-------
Scratch pad for UI automation debugging: many short Python variants (A.py through Z.py), runv.bat / runw.bat launchers, and debug screenshots.

How to use
----------
1. Pick the lettered script that matches the experiment you last used; diff against neighbors when behavior diverges.
2. Run from this folder so relative paths to images resolve: python V.py (example).
3. Use debug/ for transient captures; delete old PNGs when a flow stabilizes to save disk.
4. Promote a single canonical script elsewhere once a flow is production-ready—keep Retry/ disposable.
